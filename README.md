# Douyin downloader

> <sub>This document was generated by Anthropic's Claude Fable 5.2.</sub>

This is a script package for Miyu. It provides one tool, `douyin_dl`, which downloads videos and photo posts from Douyin and TikTok without the watermark. Videos are saved into the Videos folder and photo posts into the Pictures folder (sessions without those two folders, such as group chats, save into the workspace). You can pass it the whole share text copied from the mobile app as is, and short links are expanded automatically.

## Parameters

The tool takes the following parameters:

| Parameter | Description |
|---|---|
| `url` | The share text or link |
| `action` | `download` (default) downloads the post; `info` only reads the title, author, length and cover; `doctor` runs a self-check |
| `out_dir` | A subfolder of the Videos or Pictures folder, default `抖音` (`douyin` when saving into the workspace); absolute paths and paths that lead outside that folder are rejected |
| `quality` | `best` (default), `1080`, `720`, `worst` |
| `cookies` | A cookies.txt file in Netscape format, needed only when anonymous access is refused |
| `format` | `md` (default) or `json` |

## Behavior

This section explains how the tool fetches posts from Douyin and TikTok and how it saves the files.

- Douyin: the tool reads the post data embedded in the mobile share page (the request carries a free `ttwid` device cookie, cached for a day), removes the watermark mark, and downloads the quality chosen by `quality`; if the data cannot be read from the share page, it falls back to the web API. This part uses only the Python standard library.
- TikTok: the tool downloads through [yt-dlp](https://github.com/yt-dlp/yt-dlp); if yt-dlp is not installed, the tool reports an error and explains how to install it. With ffmpeg, the tool downloads the best separate video and audio streams and merges them; without ffmpeg, it downloads the best combined stream. yt-dlp's cache is kept in the script cache folder.
- A photo post is saved as one folder containing `01.jpg`, `02.jpg` and so on.
- The cover of a video and the first few pictures of a photo post (at most 4) are attached for the AI to look at (PNG/JPEG/GIF/WebP, ≤5 MiB, ≤8000 pixels on each side); to show them to a person, the AI opens the file with `show`.

## Dependencies

The tool needs the following programs:

- Required: Python 3
- Downloading from TikTok needs `yt-dlp` (Arch: `pacman -S yt-dlp`); installing `ffmpeg` as well is recommended

With `action=doctor`, the tool checks yt-dlp and ffmpeg one by one, and whether it can reach Douyin and obtain a device cookie.
